# ContextOS Archive

Cold storage for memory entries removed during compaction or context shifts.
Not in active memory. Recoverable on request.

## Format

```
### [YYYY-MM-DD] — [reason]

**[Category]**
- [original entry text, verbatim]
- [original entry text, verbatim]

**Replaced by:**
> [the compacted entry that took its place]
```

## Usage

- Check here when a user asks about something not in active memory
- Restore entries by adding them back to memory when they become relevant again
- Preserve original wording exactly — do not paraphrase archived content
